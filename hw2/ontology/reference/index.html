NYCU Physical AI HW2 Planning Ontology

Vocabulary used in HW2 to describe an RRT planning run, including its nodes, candidate edges, accepted tree edges, final path, and measured social and geometric properties.

Overview

This reference documents the vocabulary used by the HW2 RDF planning record. The authoritative machine-readable ontology is ontology/schema.ttl; this page presents the same classes and properties in a form that is easier to browse while implementing the assignment.

How to use this page. Look up a term here when you need its intended meaning, domain, range, or class relationship. Use the exact hw2: term shown in your Turtle output.

Classes

edge hw2:Edge

A candidate connection between two RRT nodes that was considered by the planner.

https://nycu.edu.tw/physical-ai/hw2/ontology#Edge

human activity zone hw2:HumanActivityZone

A spatial region associated with a human activity in the current test case. Every zone defined by the case must be declared, even when no edge enters it, and the individual's IRI local name must equal the zone's test-case id.

https://nycu.edu.tw/physical-ai/hw2/ontology#HumanActivityZone

node hw2:Node

A sampled or constructed point represented as a node in the RRT.

https://nycu.edu.tw/physical-ai/hw2/ontology#Node

path edge hw2:PathEdge

An accepted RRT tree edge that belongs to the final path claimed by the planner.

Subclass of: hw2:RRTTreeEdge
https://nycu.edu.tw/physical-ai/hw2/ontology#PathEdge

personal space hw2:PersonalSpace

A personal-space region associated with a person in the current test case. Every person defined by the case must be declared, even when no edge enters the space, and the individual's IRI local name must equal the person's test-case id.

https://nycu.edu.tw/physical-ai/hw2/ontology#PersonalSpace

planning run hw2:PlanningRun

One execution of the planner for a single test case, including its root, goal, and recorded planning result.

https://nycu.edu.tw/physical-ai/hw2/ontology#PlanningRun
